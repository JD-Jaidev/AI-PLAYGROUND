# AI Playground

A collection of AI-powered applications built to explore practical applications of **Generative AI, RAG, LLMs, and NLP**.

## 📊 Live Demo
[AI-Playground]()

## 🚀 Projects

### 📄 RAG PDF Analyzer

A Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and interact with their content using AI.

**Features:**
- Upload and process PDF documents
- Ask questions based on document content
- Context-aware responses
- Source-bounded answers
- Multiple LLM support

### 📑 AI Resume Analyzer

An AI-powered resume analysis tool that evaluates a resume against a specific job description.

**Features:**
- Resume PDF extraction
- Job description analysis
- ATS-style compatibility score
- Missing skills and keywords
- Resume improvement suggestions
- Visual analysis of results

### 🤖 Multi-Model AI Chatbot

A conversational AI application that allows users to interact with multiple AI models through a single interface.

**Features:**
- Multiple LLM support
- Model selection
- Conversational interface
- Compare responses from different models
- AI experimentation and model evaluation
